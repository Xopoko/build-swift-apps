# Build Optimization Recommendations

For each finding, name the affected target or file, show the observation that supports it, and explain how it affects clean, zero-change, touched, or CI builds. Suggest a change when its mechanism is clear enough to test.

Report elapsed time separately from cumulative task time. Estimate a wait-time improvement only when the evidence supports one. For an unmeasured change, describe how the same benchmark would verify it and what could regress.
