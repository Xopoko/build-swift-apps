# Security policy

## Report a vulnerability privately

Use GitHub's [private vulnerability report form](https://github.com/Xopoko/build-swift-apps/security/advisories/new).
Keep vulnerability details out of public issues, pull requests, and discussions.

Include the affected release or commit, the skill or script involved, what an
attacker could do, and the steps to reproduce it with sanitized sample data.
Remove credentials, signing material, personal details, and private URLs from
attachments.

Reports are welcome for the current release and `main`. For a vulnerability
in an external tool or agent, report it to that project's maintainers.
