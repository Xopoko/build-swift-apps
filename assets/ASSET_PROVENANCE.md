# Asset Provenance

The plugin icon family is original generated artwork created with OpenAI's
built-in image generation capability for this repository on 2026-08-13. The
original swift-bird-in-flight and orange-editor direction is recorded in the
schema-v2 prompt contract in `icon-prompt.json`. It is not an exact reproduction
of Apple Swift logo geometry, the Apple logo, the Xcode application icon, or the
Xcode hammer.

The selected source bitmap was deterministically resized with a high-quality
Lanczos filter and composited onto the declared dark brand-color base.
`icon.png` and `build-swift-apps-icon.png` are opaque 1024x1024 RGB derivatives;
`build-swift-apps-small.png` is the matching opaque 256x256 RGB derivative. No
third-party image asset was incorporated.
